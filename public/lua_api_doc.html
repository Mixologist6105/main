快速上手

脚本目录 bin/scripts/*.lua · 在软件脚本页加载/卸载 · 支持 require 加载同目录模块

模块化（require）

支持从 bin/scripts 的子文件夹加载库文件，子文件夹内的 lua 不会出现在软件的脚本列表中，适合放数学库/工具库等公共模块：

local mathlib = require "libs/mathlib"   -- 加载 bin/scripts/libs/mathlib.lua
local mathlib = require "libs.mathlib"   -- 点号写法等价
mathlib.clamp(x, 0, 100)

库文件按标准 Lua 模块写法，return 一个 table 即可。

最小示例

-- 锁定目标时画金色框
client.set_event_callback("paint", function()
    local t = client.get_target()
    if t then
        render.rect(t.x, t.y, t.w, t.h, 255, 215, 69)
    end
end)

脚本结构约定

  • 顶层代码在加载时执行一次 —— 在这里创建控件、注册事件。
  • 需要每帧执行的内容放进 paint 事件，需要清理的内容放进 unload 事件。
  • 所有回调都运行在 UI 线程，可直接读写 ui.get / ui.set。
  • 加载同名/其它脚本会先卸载当前脚本，unload → 新脚本 load。
注册任意 paint 回调后会自动显示全屏绘制覆盖窗口；全部注销或脚本卸载后自动关闭。覆盖窗口跟随软件的 Anti-OBS 设置。

事件系统

事件回调注册

client.set_event_callback(name: string, fn: function)
注册事件回调。同一事件可注册多个回调。
client.unset_event_callback(name: string, fn: function)
按函数引用移除回调。

事件列表

事件名回调参数触发时机
"paint"无每帧。在回调内调用 render.* 绘制到屏幕覆盖层
"target"target 或 nil锁定目标出现 / 切换 / 丢失时
"key_pressed"binding: string软件内注册的按键绑定被按下时
"hw_button"table { button, down }硬件盒鼠标物理按键状态变化（left/right/middle/mouse4/mouse5）
"load"无脚本加载完成后
"unload"无脚本即将卸载（清理资源）
client.set_event_callback("target", function(t)
    if t then
        client.log("locked #" .. t.id)
    else
        client.log("target lost")
    end
end)
旧式全局函数 on_key_pressed(binding) / on_unload() 仍然兼容，但新代码建议统一用事件系统。

client 命名空间

日志、系统信息、输入发送、定时器

日志与信息

client.log(value)
输出到软件 Debug 日志页。
client.get_version() → string
软件版本号。
client.screen_size() → width, height
屏幕物理像素，返回两个值。
client.time_ms() → number
系统启动以来的毫秒数（int64）。
client.get_fps() → number
当前推理 FPS。
client.get_latency_ms() → number
捕获+推理全流程延迟（毫秒，EMA 平滑）。
client.toast(message: string)
顶栏 Toast 弹窗提示，不写日志页。
client.open_url(url: string)
用默认浏览器打开链接。

运行时状态

client.get_aim_state() → table
瞄准/扳机状态：aimbot_on、aimbot_active（正在瞄准）、triggerbot_on、triggerbot_active，均为 bool。
client.get_model_info() → table
当前模型：name、input_width、input_height、classes（类别名数组，1 起始）。未加载模型时尺寸为 0。
client.get_hardware() → table
硬件盒状态：connected、device_type（"Makcu"/"Makxd"/"KmboxNet"，未连接为 nil）、hw_keyboard（硬件是否接管键盘）。
client.is_hw_button_down(button: string) → bool
硬件盒鼠标物理按键是否按下，"left"/"right"/"middle"/"mouse4"/"mouse5"。不依赖系统鼠标状态，直接读硬件上报。配合 hw_button 事件使用。

输入

client.is_key_down(vk: number) → bool
Win32 虚拟键码是否按下。
client.send_key(scan: number, down: bool)
发送扫描码按键。连接 Kmbox / Makxd 时走硬件，否则走 user32。
client.send_mouse_move(dx: number, dy: number)
相对移动鼠标（硬件优先）。
client.send_mouse_button(button: string, down: bool)
"left" / "right" / "middle"，down 省略时为 true。

定时器

client.set_interval(ms: number, fn: function) → id
每 ms 毫秒执行一次，回调在 UI 线程。
client.set_timeout(ms: number, fn: function) → id
延迟执行一次。
client.clear_interval(id) / client.clear_timeout(id)
取消定时器。脚本卸载时所有定时器自动取消。

自定义指令

client.register_command(name: string, usage: string, fn: function) → bool
在 Debug 日志页注册一条自定义指令。用户输入 /name 参数1 参数2 时触发 fn(args)，args 为字符串 table（1 起始下标）。重名（含内建指令）时返回 false。脚本卸载时自动注销，并会出现在 /help 列表中。
client.register_command("heal", "/heal <秒>", function(args)
    local sec = tonumber(args[1]) or 5
    client.log("healing for " .. sec .. "s")
end)

HTTP 请求（异步）

client.http_get(url [, headers], fn)
发起 GET 请求。headers 可选，为 table（如 { ["Authorization"] = "Bearer ..." }）。
client.http_post(url, body [, headers], fn)
发起 POST 请求，body 默认以 application/json 发送；可在 headers 里用 ["Content-Type"] 覆盖（如 application/x-www-form-urlencoded）。

回调在 UI 线程执行，收到 table：ok（2xx 为 true）、status（HTTP 状态码，网络错误为 0）、body（响应文本或错误信息）。默认超时 15 秒。

client.http_get("https://api.example.com/data", function(resp)
    if resp.ok then
        local data = json.parse(resp.body)
        client.log(data.title)
    end
end)

文件读写（持久化）

client.write_file(name, content: string) → bool
写入文本到 bin/scripts/data/name（UTF-8，自动建目录）。文件名不允许路径分隔符和 ..。
client.read_file(name) → string | nil
读取文件内容，文件不存在返回 nil。
client.file_exists(name) → bool / client.delete_file(name) → bool
检查 / 删除文件。
-- 存取自定义 JSON (账号、卡密、设置等, 格式由脚本作者自定)
client.write_file("account.json", json.stringify({ user = "name", token = "..." }))
local acc = json.parse(client.read_file("account.json"))

目标数据

client.get_target() → table | nil
当前锁定目标，无目标返回 nil。
client.get_predictions() → table[]
当前帧全部检测目标（数组，1 起始下标）。

目标 table 字段

字段类型说明
idnumber跨帧追踪 ID（-1 = 未关联）
x, y, w, hnumber边界框（屏幕物理像素）
cx, cynumber中心点
confidencenumber置信度 0~1
classnumber类别索引
aliasstring类别名

mouse 命名空间

鼠标注入 · 硬件盒已连接时走硬件（MS_* 指令），未连接回退 Win32 软件输入 · 全部返回 bool（未知按键名返回 false 并写日志）

移动

mouse.move(dx: number, dy: number) → bool
相对移动鼠标。
mouse.move_to(x: number, y: number) → bool
绝对移动到屏幕坐标。有硬件时按本机当前光标换算差值走相对注入。
mouse.position() → x, y
本机当前光标位置，返回两个值。

按键与滚轮

mouse.down(button: string) / mouse.up(button: string) → bool
按住 / 松开鼠标键："left" / "right" / "middle" / "mouse4" / "mouse5"（不区分大小写）。
mouse.click(button: string [, hold_ms: number]) → bool
单击，hold_ms 为按下保持毫秒数，默认 10（上限 10000）。
mouse.wheel(delta: number) → bool
滚轮，正值向上，120 为一格。MAK 新固件走硬件 WHEEL 指令，否则回退 Win32。
mouse.move_to(960, 540)
mouse.click("left", 30)
mouse.wheel(-120)

keyboard 命名空间

键盘注入 · 硬件盒已连接时走硬件 HID，未连接回退 Win32 · 键名与按键绑定一致 · 全部返回 bool（未知键名返回 false 并写日志）

keyboard.down(key: string) / keyboard.up(key: string) → bool
按住 / 松开按键。
keyboard.press(key: string [, hold_ms: number]) → bool
点按，hold_ms 默认 10（上限 10000）。MAK 新固件由设备端定时 KEY_PRESS，脚本线程不 sleep；否则本地下按-延时-松开的软件流程。

键名约定

字母 "A".."Z"、数字 "D0".."D9"、功能键 "F1".."F12"、"Enter" / "Escape" / "Space" / "Tab"、修饰键 "LCtrl" / "LShift" / "LAlt" / "LWin"（右侧加 R 前缀，如 "RCtrl"）、方向键 "LeftArrow" 等，与 HidKeyMapper / 按键绑定显示名一致。

keyboard.press("F1")
keyboard.down("LCtrl")
keyboard.press("C")
keyboard.up("LCtrl")

render 命名空间

屏幕覆盖层绘制 · 仅在 paint 事件内有效 · 坐标为屏幕物理像素（自动处理 DPI）· 颜色分量 0~255，alpha 省略默认 255 · 每帧上限 512 条

render.text(x, y, text, r, g, b [, a])
文字（14px Segoe UI）。
render.rect(x, y, w, h, r, g, b [, a])
空心矩形，线宽 1.5。
render.rect_filled(x, y, w, h, r, g, b [, a])
实心矩形。
render.line(x1, y1, x2, y2, r, g, b [, a])
线段。
render.circle(cx, cy, radius, r, g, b [, a])
空心圆。

示例

render.rect_filled(12, 44, 180, 24, 0, 0, 0, 100)  -- 半透明底板
render.text(18, 48, "hello", 255, 215, 69)
render.line(0, 0, 100, 100, 255, 80, 80, 180)
绘制覆盖层是独立的全屏透明窗口（点击穿透、不显示在任务栏），有 paint 回调时才显示。推理停止后目标快照会被清空，不会残留旧画面。

ui 命名空间

在软件脚本页创建控件 · 值持久化到 cfg 配置

创建控件

ui.add_toggle(text, key) → handle
开关。handle 额外含 is_on 字段。
ui.add_runtime_toggle(text, key) → handle
运行时开关，不写入 cfg。
ui.add_slider(text, min, max, unit, key, default) → handle
滑块。
ui.add_combobox(text, options, key, default) → handle
下拉框，options 为字符串数组。
ui.add_button(text, fn)
按钮，点击执行 fn。
ui.add_keychanger(text, key, default) → handle
按键绑定控件，default 为字符串或字符串数组。
ui.add_text(text) / ui.add_separator()
说明文字 / 分割线。

控件句柄

add_* 返回的 handle table：

  • handle:get() — 读当前值
  • handle:set(v) — 写值
  • handle:set_visible(b) / handle:is_visible() — 显隐控制
  • handle.key — 配置键名

参数读写

ui.get(key) → value
读任意参数（bool / number / string / table）。
ui.set(key, value)
写任意参数。
ui.is_key_down(key) → bool
按键绑定控件当前是否有键按下。
软件设置保留键（语言、GPU、Anti-OBS 等 Menu Settings 键）Lua 无法读写，调用会被拒绝并输出日志。

json 命名空间

JSON 解析与序列化（System.Text.Json）

json.parse(text: string) → table | nil
解析 JSON 字符串。对象 → 字符串键 table，数组 → 1 起始整数键 table，null → nil。解析失败输出日志并返回 nil。
json.stringify(value) → string
把 table/number/string/bool 序列化为 JSON。键为连续整数 1..n 的 table 输出为数组，其余输出为对象。
local t = json.parse('{"a": 1, "list": [10, 20]}')
client.log(t.list[2])  -- 20
client.log(json.stringify({ name = "braytech", flags = { true, false } }))

全局函数

命名空间之外的内置函数

lang(zh: string, en: string) → string
按软件当前语言返回对应字符串，用于控件文本本地化。
require "name"
加载 bin/scripts 目录下的 name.lua 模块，支持子文件夹（require "libs/math" 或 require "libs.math"），子文件夹内的文件不出现在脚本列表。

完整示例

更多示例见 bin/scripts/lua_api_test.lua

-- 目标高亮 + 中心准星 + 信息面板
local sw, sh = client.screen_size()
local cx, cy = sw / 2, sh / 2

client.set_event_callback("paint", function()
    -- 中心十字
    render.line(cx - 12, cy, cx + 12, cy, 255, 215, 69, 200)
    render.line(cx, cy - 12, cx, cy + 12, 255, 215, 69, 200)

    -- 所有检测目标
    local preds = client.get_predictions()
    for _, p in ipairs(preds) do
        render.rect(p.x, p.y, p.w, p.h, 255, 255, 255, 120)
        render.text(p.x, p.y - 16,
            string.format("#%d %s %.0f%%", p.id, p.alias, p.confidence * 100),
            255, 255, 255, 180)
    end

    -- 锁定目标高亮
    local t = client.get_target()
    if t then
        render.rect(t.x - 2, t.y - 2, t.w + 4, t.h + 4, 255, 215, 69)
        render.line(cx, cy, t.cx, t.cy, 255, 80, 80, 140)
    end

    -- 信息条
    render.rect_filled(12, 44, 180, 24, 0, 0, 0, 100)
    render.text(18, 48,
        string.format("fps: %.0f  preds: %d", client.get_fps(), #preds),
        175, 175, 175)
end)

client.set_event_callback("target", function(t)
    client.log(t and ("locked #" .. t.id) or "target lost")
end)
